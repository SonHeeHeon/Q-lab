# 계좌 프로파일 (account_profiles)

계좌 타입별 퀀트의 기준 정보 디렉터리. 계좌마다 "매매 가능 유니버스 / 세금 /
제약 / 투자 기한(horizon)"이 달라, 전략·백테스트·비중이 계좌별로 분리된다.
(설계: `.omc/plan/2026-07-29_account-type-quant-dc-2029.md`)

## 계좌 프로파일 요약 (2026-07-29 기준)

| 계좌 | 매매 가능 | 세금 | 제약 | horizon |

  **자문 모드**(주간 인사이트 랭킹 참고, 주문 수동). 슬롯 교체 시 계좌 검증
  순서(PAPER→REAL→ISA) 규칙 재정의는 사용자 명시 승인으로만.

## 파일

- `kis_dc_etf_allowlist.csv` — KIS 퇴직연금(DC) 매매 가능 ETF + 위험/안전 분류.
  - 형식: `code,name,risk_class,memo` (risk_class: `risk`|`safe`), `#` 주석 허용.
  - 시드는 대표 ETF 수동 구성(연구용) — **KIS 퇴직연금 주문 화면과 대조해 검수·확장할 것.**
  - 유지보수: 종목 추가/삭제 시 이 CSV만 수정하면 유니버스(`ETF_KR_DC_RISK`/`ETF_KR_DC_SAFE`)에 반영된다.
- (추후) 연금저축·ISA용 allowlist도 같은 형식으로 이 디렉터리에 추가한다.

## DC 68/32 설계 메모

목표 비중은 위험 68% / 안전 32% — 규제 상한 70%에서 2%p 버퍼를 남겨 리밸런스
사이 드리프트를 흡수한다(실계좌는 KIS 퇴직연금 시스템이 70% 초과 주문을 추가
차단하는 이중 방어).
